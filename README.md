## Featured work

### 1. Atlas

I’m building Atlas, a free, open-source Chrome extension that adds a project sidebar. Close Chrome and come back later, and Atlas restores each project’s tabs, home page, and notes so you can pick up where you left off. I’m building it first for Arc users who want to keep their work organized in Chrome when [Arc for Mac and Windows shuts down on December 22](https://resources.arc.net/hc/en-us/articles/44412972248471-Arc-Sunset-Key-Dates-and-What-to-Expect).

**Product decision:** On November 18, I cut the custom browser and all the AI features to focus on one promise: never lose your place in a project. A lot of the people I researched were frustrated by AI being pushed on them. Keeping their work intact mattered more than adding another AI feature.

**In development, launching December 2026.** I plan to publish the source and launch on the Chrome Web Store before December 22.

### 2. [Claude Token Management](https://github.com/DrewDawson2027/claude-token-management)

I built an open-source add-on for Claude Code users who want to avoid burning through usage limits on work that doesn’t need to happen, like reading the same file repeatedly or spinning up too many agents.

**Product decision:** I put guardrails before the wasteful action and tuned the thresholds using 674 real sessions. The hard stop triggered in fewer than 1% of those sessions. I wanted to catch costly outliers without interrupting normal work.

[Watch the recorded demo](https://github.com/DrewDawson2027/claude-token-management#demo) · [Explore the code](https://github.com/DrewDawson2027/claude-token-management)

### 3. [SkillTrace](https://drewdawson2027.github.io/)

I built SkillTrace for candidates who want to show what they know and hiring teams that want to see the evidence. It turns a GitHub repo into an AI interview, checks answers against the source code, and produces a shareable summary with links to the evidence.

**Product decision:** I designed the summary around evidence a reviewer can inspect, so they don’t have to take an AI score at face value.

[Open the demo](https://drewdawson2027.github.io/)
